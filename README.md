# 【独立版】仿鱼泡找工人，灵活用工招聘系统

源码地址：ym7k.com/18889/

这套是对标鱼泡网模式的独立灵活用工招工小程序，主打蓝领零工、日结兼职、短期活、暑假工、工地招工，适合劳务队、包工头、本地劳务公司搭建招工找活平台，独立部署，不需要依赖其他框架。

### 工人端（找活端）

- 首页工种分类：工厂普工、日结兼职、安保安检、装卸分拣、司机、客服文员、暑假工等自定义工种
- 两大核心板块：找工作、找工人
- 可以免费发布个人找活信息，填写年龄、工龄、意向工种、期望工作地、个人优势
- 浏览招工信息，查看岗位地点、薪资，支持联系招工方
- 个人中心：我的找活信息、收藏、浏览记录、联系记录
- 实名认证、积分充值、邀请好友、团队分销功能

### 招工方（包工头 / 老板）

- 发布招工岗位，支持设置日结、短期、暑假工、实习盖章类岗位
- 岗位可付费置顶，提升曝光，吸引工人接单
- 筛选工人简历，联系合适工人，快速招人
- 岗位状态管理：招人中 / 招满，后台审核管控

### PC 管理后台完整模块

- 招工管理：招工信息审核（待审核、已审核、驳回、招人中、招满），新增、启用禁用岗位，置顶记录
- 找活管理：管理工人发布的求职信息
- 会员管理、实名认证管理、积分管理：积分充值消耗、置顶扣费
- 工种分类：自由新增、修改工种，适配工地、工厂、学生兼职、宝妈居家活
- 代理管理：开通区域代理，适合按城市做劳务分站
- 提现管理、公告管理、权限管理、系统配置、手机号查看记录

### 核心亮点

✅ 独立版源码，私有化部署，仿鱼泡找工人业务逻辑
✅ 双向发布：老板招工、工人找活，双边流量
✅ 适配多种场景：工地零工、日结临时工、暑假工、实习、宝妈兼职、短期项目
✅ 置顶付费盈利、积分体系、邀请好友、团队分销、区域代理
✅ 实名认证机制，降低虚假信息风险
✅ 工种自定义，地区筛选，精准同城劳务匹配
✅ 状态审核流，平台可控，可管控招工信息质量

### 适合落地

建筑劳务招工、本地零工平台、暑假工中介、日结兼职平台、工厂短期临时工招募、灵活用工小程序
